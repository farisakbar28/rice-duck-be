# R2 Freeze Manifest — Governance, Semantics, and Reproducibility

> **Status:** CANONICAL Phase-6 pre-comparator freeze documentation.
> **Current corrected candidate:** `FREEZE_ID = R2-FREEZE-2026-08-26.5`,
> `FREEZE_EFFECTIVE_FROM = 2026-08-26`.

## 1. What "frozen" means — and what it does NOT mean

`frozen=true` in the simulation/visualization model metadata means exactly
one thing: the model/registry identity is an **immutable validation target**
for retrospective validation.

It does **NOT** mean:

- empirically validated (`validated=true` does not exist in R2 metadata);
- accurate (no accuracy claim is attached to the freeze);
- complete (yield is conditionally available inside its supported evidence
  domain; feed cost, cage total, and full profit remain unavailable).

## 3. Where the freeze lives in code

- `app/data/seed.py`: `MODEL_FROZEN`, `FREEZE_ID`, `FREEZE_EFFECTIVE_FROM`
  (module constants outside `PARAMETER_REGISTRY`; they are governance state,
  not scientific parameters).
- `app/schemas/dss.py::ModelMeta`: `frozen: bool`, `freeze_id: str | None`.
- `app/services/simulation_service.py`: wires both from seed constants —
  never a hardcoded literal.

## 4. Machine-readable manifest

Generated by the research-only harness:

```bash
python -m validation --source-dir /path/to/research/files
```

Artifacts (per run under `validation/results/<run_id>/`, latest manifest
mirrored to `validation/freeze_manifest.json`):

- `freeze_manifest.json` — identity, formula registry groups + disabled
  legacy IDs, full parameter dump, pending/unavailable parameters, lookup
  states, SHA-256 of canonical artifacts, active-test summary, workbook
  fingerprints;
- `v1_computational.json` — docs/06 §19 matrix mapped to active tests;
- `synthetic_cases.json` — B01–B18 raw responses via the canonical HTTP path
  plus supported-age (21 vs 30) numeric invariance evidence;
- `fixture_manifest.json` — source roles/policies/cohort status;
- `component_eligibility.json`, `calendar_validation.json`,
  `yield_validation.json`, `purchase_validation.json`,
  `revenue_validation.json`, `stress_results.json`, `expert_transfer.json`;
- `validation_report.md` — component-specific conclusions; never a universal
  accuracy score.

The manifest contains **no secrets** and **no raw workbook contents**.

## 5. Official execution gate

Official frozen-validation artifacts require ALL of:

1. clean Git working tree (`git status --porcelain` empty);
2. `git rev-parse HEAD` resolvable — recorded as the actual backend commit;
3. `MODEL_FROZEN = true`;
4. `FREEZE_ID` set;
5. full active test suite passing (`tests/legacy_invalid/` stays excluded);
6. `PARAMETER_REGISTRY_VERSION` equals the expected frozen value;
7. raw recap and clean-v10 comparator present with valid fingerprints;
8. cohort reconstruction successful with no `SOURCE_VERSION_MISMATCH`;
9. clean Git, known HEAD, passing tests, and known freeze/registry identities.

Any unmet condition produces watermarked output:
`run_mode = NON_OFFICIAL_PRECOMPARATOR_BLOCKED`. A dirty tree additionally reports
`OFFICIAL_VALIDATION_BLOCKED_DIRTY_TREE`.

### Phase 5C empirical source conditions

Source discovery alone is insufficient for an official empirical run. The raw
recap and clean-v10 comparator must both be present with valid fingerprints;
cohort reconstruction must succeed at 44 raw / 36 clean / 8 excluded, strict
supported-domain N=17, and calendar N=12; and no
`SOURCE_VERSION_MISMATCH` may be reported. These conditions supersede the
earlier permissive missing-source wording above.

The legacy-simulation workbook is independently fingerprinted for its
audit-only role. It never substitutes for raw/clean evidence and is never a
parameter, prediction, or comparator source.

## 6. Anti-calibration guarantees

The harness cannot tune the model: it contains no fitting/optimization code,
never rebinds seed/registry identifiers, never monkeypatches parameters, and
is statically guarded by `tests/test_validation_isolation.py`. Comparator
residuals are reported, never used to modify `app/data/seed.py`,
`app/engines/r2/`, or any SSOT coefficient. Any future scientific change
requires a new registry/model version and a fresh pre-freeze review.
